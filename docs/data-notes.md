# 数据口径与已知限制

## 数据源：akshare（免费爬虫型接口）

- 日线：东财 `stock_zh_a_hist`（不复权原始价）；复权因子：新浪 `stock_zh_a_daily`（hfq-factor）
- 实时快照：东财 `stock_zh_a_spot_em`（全市场一次拉取，本地过滤）
- 新闻：东财 `stock_news_em`；交易日历：新浪 `tool_trade_date_hist_sina`
- 指数：东财 `stock_zh_index_spot_em`（失败回退新浪）

**性质与风险**：爬虫接口，可能限流/改版/抽风。系统做了：请求间限速（0.6s）、
失败重试 3 次指数退避、单标的失败不中断整批、本地 SQLite 是唯一事实源（断网可回测）。
akshare 升级前建议先跑一遍 `pytest` 与 `smoke_e2e.py`。

**网络兼容补丁（app/utils/netcompat.py + akshare_source）**，针对实际部署中发现的三个问题：
1. **IPv6 链路异常**：部分网络下东财 IPv6 连接被重置而 IPv4 正常 → 出站连接强制优先 IPv4
2. **编号子域名不可达**：akshare 硬编码的 `82.push2.eastmoney.com` 在部分网络被封 →
   出站时重写到主域名 `push2.eastmoney.com`（同一套 API）
3. **WAF 识别爬虫 UA**：请求注入浏览器 User-Agent，降低被拦截概率

即使如此，**高频连续请求仍会触发东财 WAF 对 IP 的临时封禁（数分钟~数小时，连接被重置）**。
这是数据源侧的客观限制：系统会在封禁期间自动降级（实时行情失败、本地库照常回测），
封禁解除后自动恢复。请勿用脚本高频轰炸数据源。

## 单位标准化

| 字段 | 存储单位 |
|---|---|
| 成交量 | 股（akshare 原始为手，入库 ×100） |
| 成交额 | 元 |
| 涨跌幅 | 百分数（10.0 = +10%） |
| 日期 | "YYYY-MM-DD" 文本（无时区问题） |

## 复权口径

库存**不复权原始价 + adj_factor（hfq 因子）**，加载时用最新因子法：
`前复权价 = 原始价 × adj_factor / 最新adj_factor`。
理由：若直接存前复权价，每次除权后历史价格整体平移，增量追加会产生断点；
原始价+因子天然支持幂等 upsert。**同一策略内勿混用不同复权口径。**

## 涨跌停近似

涨跌停判断用 `pct_change ≥ 9.8%` 近似（容忍四舍五入），阈值默认 10% 可配。
**未区分** ST（±5%）、创业板/科创板（±20%）、北交所（±30%）——这些标的的
涨跌停判断会不准。v1 自选池建议选主板股票。

## 回测引擎假设

- 成交价 = 次日开盘价 ± 滑点（0.01 元/股可配），不含开盘竞价细节
- 零股不支持：整手 100 股，卖出非整手拒单
- 限价单保守模型：仅当开盘价穿越委托价时按委托价成交
- 停牌日持仓按最后收盘价估值
- 不计：分红送股现金收益（仅价格复权）、融资融券

## 模拟盘行情限制

akshare 快照约延迟 **30~60 秒**、非 tick 级、无推送（30s 轮询）。
因此：日线/小时级策略模拟完全可用；**分钟级高频模拟不承诺精度**。
模拟盘「当日成交明细」以轮询到的快照价为基准，与真实盘口有偏差，仅作学习研究。

## 指数历史白名单

允许入库历史的指数：000300（沪深300，回测基准）、399001（深证成指）、399006（创业板指）。
**上证指数（000001）与平安银行（000001）代码冲突**，故上证指数仅提供实时快照，无历史入库。

四组均走新浪源（东财在本机网络不可用），按组独立 TTL 缓存：
