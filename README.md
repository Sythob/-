# 唯我量化 — AI 智能量化交易系统

个人使用的 A股量化研究平台：数据获取 → 策略回测 → 机器学习信号 → AI 辅助分析 → 模拟盘，全流程 Web 可视化（FastAPI + Vue3 单进程架构，Windows 本机运行）。

## 核心功能

### 数据层
- **多源回退链**：腾讯（主源）→ 新浪 → 东财，任一源故障自动切换；东财部分接口被 WAF 封禁时按可用接口自适应
- **数据完整性**：原始价 + 复权因子存储（最新因子法 qfq）、交易日历过滤（剔除节假日脏数据）、复权因子尖峰修复、成交量/换手率单位统一
- **自动保鲜**：交易日开盘前/收盘后自动同步；30 分钟自愈看护（数据滞后自动补同步并重试）；**同步范围自动覆盖模拟账户持仓**（自选池之外的持仓股也不会用旧价格估值）
- **市场数据**：行业板块行情（点击查看成分股）、资金流向排行（行业/概念）、每日龙虎榜、北向资金（汇总 + 近 30 日走势）
- **候选池**：做 T 候选池（全市场扫描，按市场强弱动态收紧）、打板候选池（涨停/连板标注 + 风险提示，收盘后自动刷新）

### 回测引擎
- 自研事件驱动引擎，还原 A股规则：T+1、整手 100 股、涨跌停拒单、佣金/印花税/过户费/滑点
- **防未来函数铁律**：信号 t 收盘产生 → t+1 开盘成交；ML 特征 shift 截断三重校验
- 指标齐全：年化收益/最大回撤/夏普/胜率/盈亏比/换手率 + 沪深300 对比 + HTML 报告
- **智能批量回测**：8 组策略 × 自选池自动跑近 5 年，记录胜率与收益率战绩排行榜；支持参数优化

### 策略
- 内置 9 个策略：双均线、RSI 反转、布林突破、网格、海龟、波段趋势、因子轮动、一夜持股、ML 信号
- **自然语言生成策略**：描述中文意图 → 大模型生成代码 → 白名单校验 → 样本空跑通过才入库（失败自动带错误重试）

### 机器学习
- 自研 15+ 技术指标（配对拍测试）、~30 维特征（严格防未来函数）、LightGBM/XGBoost + Walk-Forward 滚动验证
- 每周可自动重训并监控 OOS 性能退化

### AI 能力（可插拔：DeepSeek / Claude / Qwen / 本地 Ollama）
- **每日复盘**：收盘后自动生成（15:15 前拒绝生成；数据非最新交易日拒绝生成，绝不拿旧数据充当日行情）
- **预测台账闭环**：报告中的每条预测自动入账 → 次日用目标日实际行情逐条核验 ✅/❌/⚠️ → **错误逐条归因（错在哪条数据依据）+ 改正教训** → 沉淀进后续报告；「预测战绩」面板统计准确率
- **每周周报**（周五 18:30）：本周行情/操作/预测战绩复盘 + 下周预测（同样入台账核验）
- **新闻情绪**：每日抓取 → LLM 逐条打分（利好/中性/利空 + 理由）
- **多智能体分析**：4 分析师并行（技术/消息/资金/环境）→ 研究经理 → 交易员 → 风控官；支持名称或代码发起；失败分析师自动补重试
- **热点预测**：今日热点新闻 → 明日行情预测
- **下单 AI 风控**：block/warn/off 三档
- **AI 助手**：悬浮窗可拖动，注入实时市场状态回答提问

### 模拟盘
- 交易时段 30 秒行情轮询撮合，与回测同一套规则，进程重启状态不丢
- **按股票名称下单**（模糊匹配，歧义提示）；市价/限价 + 止损/止盈条件单
- **同花顺对接**：导出文件导入（持仓/交割单，镜像覆盖）、一键导出对照
- 净值曲线、持仓实时估值（红涨绿跌）

### 界面
- 8 个页面：总览 / 行情 / 市场数据 / 回测 / 策略 / 模拟交易 / AI 报告 / 系统
- **4 套主题一键切换**：深蓝商务 / 浅色简约 / 暗色科技 / 护眼米色（记住选择，图表同步适配）
- 同花顺风格 K 线（MA/BOLL + MACD/KDJ/RSI 副图）、分时图、日/周/月/季/年跨度

## 快速开始

1. 双击 `start.bat`（自动启动后端 + 前端；开发模式 http://localhost:5173，生产模式 http://127.0.0.1:8000）
2. 首次运行自动建库、同步交易日历与自选池数据
3. 在 `backend\.env` 配置大模型（任选其一）：

```ini
# DeepSeek（默认）
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-xxx

# 或本地 Ollama（免费，需先安装 Ollama 并执行 ollama pull qwen2.5:7b）
LLM_PROVIDER=local
LOCAL_BASE_URL=http://127.0.0.1:11434/v1
LOCAL_MODEL=qwen2.5:7b
```

未配置任何 Key 时自动使用模拟模型（离线可跑全流程）。完整配置见 `.env.example`。

## 常用命令

```bash
cd backend

# 手动启动后端
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 同步自选池+持仓数据
.venv\Scripts\python scripts/sync_data.py

# 命令行回测
.venv\Scripts\python scripts/run_backtest.py --strategy dual_ma --symbols 600519 --start 2020-01-01 --end 2023-12-31

# 训练 ML 模型
.venv\Scripts\python scripts/train_model.py --symbols 600519,000001

# 多智能体分析（命令行）
.venv\Scripts\python scripts/analyze_multiagent.py 600519

# 全量测试（172 个，全程离线）
.venv\Scripts\python -m pytest tests -q

# 前端开发
cd ../frontend && npm run dev
```

## 目录结构

```
backend/
  app/
    api/          REST 接口（market/backtest/strategy/ml/paper/ai/system）
    data/         数据源抽象（多源回退）、同步、日历、复权、市场数据扩展、打板/做T筛选
    engine/       事件驱动回测引擎、撮合、费用、绩效指标
    strategies/   内置策略 + 自然语言生成（generated/，不入库）
    ml/           指标、特征、Walk-Forward、模型注册表
    llm/          可插拔 Provider（deepseek/claude/qwen/local/mock）+ 任务（复盘/周报/预测台账/新闻/多智能体/风控/代码生成）
    paper/        模拟盘引擎、行情轮询、AI 风控
    scheduler/    15 个定时任务（同步/候选池/复盘/周报/结算/自愈）
  scripts/        数据同步、回测、训练、多智能体、看护进程
  tests/          172 个离线测试（数据源与 LLM 全部 mock）
frontend/
  src/views/      8 个页面
  src/components/ K线/分时/图表/AI 助手
  src/themes.ts   4 套主题定义
data/             运行时数据（SQLite、模型、日志，不入 git）
docs/             架构说明、数据口径、策略指南
```

## 数据源说明

- 主源腾讯，新浪兜底，东财部分接口可用（个股资金流排行等被 WAF 封禁，系统按实测可用性自动选择）
- 北向资金 2024-08 起盘中实时数据停发，仅收盘后日度数据
- 打板候选的换手率走腾讯批量报价（一次请求全量），北交所（4/8/9 开头）历史日线多数源不可用，连板按单板计算
